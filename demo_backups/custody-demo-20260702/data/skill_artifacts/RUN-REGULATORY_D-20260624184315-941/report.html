监管意图

政策背景为规范境内企业境外放款业务，维护外汇市场秩序，防范跨境资金流动风险。
监管目标规范境内企业境外放款行为，促进跨境资金有序流动，服务实体经济。
风险关切境外放款可能涉及资本外逃、洗钱、逃税等风险，需加强真实性、合规性审查。
预期效果建立统一的本外币境外放款管理框架，实现宏观审慎管理，防止资金无序流出。
